# Manual Maggot King Reminder

A manual reminder with sidebar buttons and a standard RuneLite infobox.

| Selected style | Display |
| --- | --- |
| Ranged | Protect from Missiles inside a green poison splat |
| Magic | Protect from Magic inside a yellow disease splat |

Open **Manual Maggot King Reminder** in the sidebar and click **Ranged** or **Magic** to mark that style. Press **`.`** while the game has keyboard focus to switch to the other style. Change or clear **Swap hotkey** in the plugin settings to use a different key.

The sidebar and infobox always show the same selection. The reminder starts on Ranged when enabled. Its selection stays as you set it until you click a button or press the hotkey; attacks, deaths, phase changes and world hops do not change it.

Hold Alt to reposition the infobox, or use its context menu to detach it from other infoboxes.
